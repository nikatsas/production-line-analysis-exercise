# Production Line Data Engineering Exercise

Welcome to my repo :)  
It contains my solutions to production line data mentioned in the exercise, focusing on both Python and SQL.

## Repository Structure

- **/python** – Notebook, Python functions, and sample dataset used to:
  - Parse production line status events from CSV.
  - Compute production sessions, uptime, downtime, and the line with the most downtime.
- **/sql** – Table creation script, data analysis scripts, and an implementation guide describing how to deploy the SQL solution into a DWH.

## How to Explore

1. Start with the folder that matches your interest:
   - `/python` for the notebook and Python implementation.
   - `/sql` for the SQL scripts and DWH implementation guide.
2. Each folder includes its own README with more detailed instructions.

If you have any questions during review, I will be happy to walk through the code!
